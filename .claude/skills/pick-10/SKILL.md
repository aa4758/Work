# /pick-10 — 투자팀 워크플로우

인자(선택): 시장(`US`/`미장`/`미국` → 미국 모드, 없으면 한국), `후보 N개`(기본 30), `이어서`, `폴더 <경로>`.

당신(메인 세션)은 **진행자**입니다. 전체 흐름은 당신만 유지하고, 종목을 직접 판단하지 않습니다.

## 컨텍스트 규칙 (토큰 절약)
- 하위 에이전트는 각자 독립 컨텍스트에서 자기 작업만 하고 종료합니다. 대화 내역을 넘기지 않습니다.
- 하위 에이전트 프롬프트에는 **모드·폴더·날짜 + 그 에이전트의 입력**만 넣습니다. 전략·형식은 에이전트 정의에 있으니 반복하지 마세요.
- 에이전트 간 핸드오프는 **`handoff.py` 출력 또는 에이전트가 반환한 표**만 전달합니다. 리포트 전문을 Read 하지 마세요.
- 같은 단계의 에이전트는 한 메시지에서 병렬로 호출합니다.

`H` = `python Investment/agent_tools/handoff.py <폴더>` (저장소 루트에서 실행)

## 0단계 — 준비
- 폴더: 인자에 `폴더 <경로>`가 있으면 그 경로(앱은 마지막 미국 장 마감일로 정해 넘김), 없으면 `reports/YYYY-MM-DD/` (미국 모드 `reports/YYYY-MM-DD-US/`).
- 미국 모드: `python Investment/agent_tools/market_data.py screen-us --top N > <폴더>/00_screen.json` (규칙·근거: Investment/SCREENING.md).
  후보를 임의로 빼거나 더하지 않습니다. 비주식 자산 `TLT IEF GLD SLV` 를 항상 추가합니다.
  스크리너가 error 면 WebSearch로 S&P500 시총·거래대금 상위 N종목을 쓰고, 규칙 기반이 아님을 보고에 명시합니다.
- 한국 모드: `python Investment/agent_tools/market_data.py screen --market ALL --top 60 --min-value 100` 에서 업종이 쏠리지 않게 N개.
- 후보 목록(티커, 종목명)과 선정 방식을 `<폴더>/00_universe.md` 에 저장.

## 1단계 — 분석
**1a (병렬)**: `chart-analyst`(주식 + 비주식 자산 전부), `fx-analyst`(주식 후보), 미국 모드는 `macro-analyst`(폴더·날짜만).
**1b**: 차트가 끝나면 fx·macro 를 기다리지 말고 `H survivors` 를 실행해 나온 티커만으로
`fundamental-analyst`, `news-analyst`, `sentiment-analyst` 를 병렬 호출합니다.
(차트 -2 는 최소 기준상 이미 탈락이라 나머지 분석이 결과를 바꿀 수 없습니다.)
누락된 리포트는 해당 에이전트만 1회 재호출합니다.

## 2단계 — 찬반 토론
1. `H debate` → 출력 전체를 `bull-advocate`·`bear-advocate` 프롬프트에 넣어 병렬 호출 → 05_bull.md, 06_bear.md.
   토론 대상이 0개면 2단계를 건너뜁니다.
2. 반박 라운드: 각자에게 **상대가 반환한 강도표**와 "반박 라운드"를 전달해 병렬 호출 → 05_bull_rebuttal.md, 06_bear_rebuttal.md.

## 3단계 — 결정
`H final` → 출력 전체를 `decision-maker` 프롬프트에 넣어 호출 → 08_decision.md (미국 모드는 picks.json 도).

## 4단계 — 보고
결정권자가 반환한 결론 표(10개 미만이면 현금 슬롯 수와 이유 먼저)와 폴더 경로를 보여주고,
"투자 권유가 아니며 최종 판단과 책임은 본인에게 있다"는 고지를 붙입니다.
데이터 도구 실패가 절반 이상이었다면 신뢰도가 낮다고 먼저 알립니다.

## 이어서 실행 (인자에 `이어서`)
사용 한도 등으로 멈춘 실행을 **같은 폴더**에서 이어 갑니다 (폴더는 0단계와 같은 규칙).
- 폴더가 없으면 처음부터 정상 실행합니다.
- 있으면 0단계를 다시 하지 않고 기존 후보를 그대로 씁니다 (인자의 후보 수 무시).
- 없거나 비어 있는 산출물의 에이전트만 실행합니다: 01·07·09 → 02·03·04 → 05·06 → 05/06_rebuttal → 08 (미국 모드는 picks.json).
  핸드오프는 위와 같이 `H` 로 다시 만듭니다.
- 보고 맨 앞에 "이어서 실행: 기존 산출물 X개 재사용, Y개 새로 작성"을 적습니다.
