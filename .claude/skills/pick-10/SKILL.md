# /pick-10 — 투자팀 10종목 선정 워크플로우

인자(선택): 후보 종목 목록, 테마, 시장(KOSPI/KOSDAQ), 후보 수. 예) `/pick-10 반도체·조선 위주로 후보 25개`

당신(메인 세션)은 **진행자(모더레이터)**입니다. 직접 종목을 판단하지 말고, 팀원(서브에이전트)을 순서대로 호출하고
결과를 전달하세요. 서브에이전트는 다른 서브에이전트를 부를 수 없으므로 모든 호출은 당신이 합니다.

## 0단계 — 준비
1. 오늘 날짜로 `reports/YYYY-MM-DD/` 디렉터리를 만듭니다.
2. **후보군(유니버스) 구성** — 기본 30종목:
   - 사용자가 종목을 지정했으면 그대로 사용.
   - 아니면 `python SetUp/agent_tools/market_data.py screen --market ALL --top 60 --min-value 100` 으로
     시총 상위·거래대금 100억 이상 종목을 받고, 업종이 한쪽에 쏠리지 않게 30개로 줄입니다.
   - screen이 실패하면(KRX 로그인 필요 등) WebSearch로 코스피·코스닥 시총/거래대금 상위 종목을 모아 구성하고,
     이 사실을 기록합니다.
3. 후보 목록(코드, 종목명, 시장, 선정 기준, 데이터 출처)을 `reports/YYYY-MM-DD/00_universe.md` 에 저장.

## 1단계 — 분석가 5명 (병렬)
**한 메시지에서 Agent 도구를 5번 동시에 호출**하세요. 각 프롬프트에 날짜, 보고서 폴더 경로, 후보 목록 전체(코드+종목명)를 넣습니다.
- `chart-analyst` → 01_chart.md
- `fundamental-analyst` → 02_fundamental.md
- `news-analyst` → 03_news.md
- `sentiment-analyst` → 04_sentiment.md
- `fx-analyst` → 07_fx.md

모두 끝나면 5개 파일이 생성됐는지 확인합니다. 누락된 리포트가 있으면 해당 에이전트만 재호출합니다(1회).

## 2단계 — 찬반 토론
1. `bull-advocate` 와 `bear-advocate` 를 **병렬 호출** (1단계 리포트 경로 전달) → 05_bull.md, 06_bear.md
2. **반박 라운드(1회)**: 두 에이전트를 다시 병렬 호출해 상대 리포트를 읽고 반박하게 합니다.
   결과는 각자 파일 끝에 `## 반박 라운드` 섹션으로 추가하도록 지시하세요.

## 3단계 — 결정
`decision-maker` 를 호출합니다 (보고서 폴더 경로와 날짜 전달) → 08_decision.md

## 4단계 — 사용자 보고
08_decision.md 의 **최종 10종목 표**(기준가·손절가·익절가 포함), 결정 근거 요약, 예비 후보를 사용자에게 보여주고
전체 리포트 폴더 경로를 알려줍니다. 마지막에 "투자 권유가 아니며 최종 판단과 책임은 본인에게 있다"는 고지를 붙입니다.

## 주의
- 데이터 도구 실패가 많았다면(시세·재무·수급 중 절반 이상 "데이터 없음") 결과 신뢰도가 낮다는 점을 사용자에게 먼저 알리세요.
- 필요한 키/환경: `DART_API_KEY`(재무), `KRX_ID`/`KRX_PW`(최신 pykrx의 시총·수급 조회). 없으면 해당 부분은 웹검색으로 대체됩니다.
