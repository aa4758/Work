# 경제교육 투자 앱 - MVP 뼈대

## 이 코드가 하는 일
- 상장사 약 4,000개 중에서 검색해 **보유 수량과 함께** 종목 등록 (무료 슬롯 3개 제한 시뮬레이션)
- 보유 비중을 자동 계산해 트리맵으로 시각화

  ```
  비중(%) = (보유수량 × 현재주가) ÷ 전체 평가금액 × 100
  ```

  비중은 DB에 저장하지 않습니다. 주가가 매일 바뀌면 비중도 함께 바뀌므로,
  변하지 않는 **보유 수량만 저장**하고 비중은 화면을 그릴 때마다 계산합니다.
- 종목을 선택하면 DART 실제 재무 기반 지표 해설을 보여줌 (해설 문장은 아직 규칙 기반)
- 등록 내역은 SQLite에 저장되어 앱을 껐다 켜도 유지됨

## 데이터 출처: 예시 데이터 + 실제 DART + 주가 자동 수집
- 사이드바에서 "실제 DART 데이터 사용"을 켜면 `dart_client.py`가 전자공시시스템(OpenDART)에서
  실제 재무제표를 받아와 ROE, 부채비율, 영업이익률, EPS, BPS를 계산합니다.
- **조회 연도는 자동입니다.** 추정 최신 연도부터 거꾸로 내려가며 실제 공시 데이터가 있는
  첫 연도를 찾습니다 (`find_latest_year_with_data`, 최대 4개 연도). 회사마다 결산월과
  공시 시점이 달라서 연도를 고정하면 빈 결과가 나오기 때문입니다.
- 큰 금액은 `333조 6,059억 원`처럼 조/억 단위로 변환해 보여줍니다.
- "주가 자동 수집(pykrx)"을 켜면 `price_client.py`가 KRX 최근 거래일 **종가**를 받아와
  PER, PBR을 자동 계산합니다. (실시간이 아니라 전 거래일 종가 기준)
  - 자동 수집이 실패하면 사이드바 아래 "현재 주가"에 직접 입력한 값으로 계산합니다.
- DART 조회에 실패하면 자동으로 `MOCK_STOCK_DATA`(예시 5종목)로 대체되어 앱이 멈추지 않습니다.

## AI 지표 해설 (`llm_client.py`)
- `ANTHROPIC_API_KEY`가 있으면 Claude(`claude-opus-5`)가 지표를 초보자 눈높이로 설명합니다.
- **키가 없으면 기존 규칙 기반 해설로 자동 동작**합니다. 코드 수정 없이 키만 넣으면 전환됩니다.
  ```
  Security/ANTHROPIC_API_KEY.env  →  ANTHROPIC_API_KEY = sk-ant-...
  ```
- 점검: `python llm_client.py` (상태 확인) / `python llm_client.py --prompt 삼성전자` (프롬프트 미리보기)

### 투자자문업 규제 회피 장치 (2중 방어)
1. **시스템 프롬프트**에서 매수·매도·주가 예측·단정 표현을 금지하고, 주어진 숫자 밖의
   사실(업종 평균, 경쟁사, 향후 전망)을 지어내지 못하게 막습니다.
2. **생성 결과 재검사** — `contains_forbidden()`이 금지 표현("매수", "유망", "상승할 것" 등)을
   찾으면 그 응답을 **버리고** 규칙 기반 해설로 되돌립니다. DB에도 저장하지 않습니다.
   프롬프트만 믿지 않는 이유는, LLM이 지시를 어길 가능성이 0이 아니기 때문입니다.
3. 화면에 "투자 권유가 아니다"라는 고지 문구를 항상 함께 노출합니다.

해설은 `explanation_cache` 테이블에 캐시됩니다(30일). 캐시 키는 지표 값의 SHA-256이라
주가가 조금 움직인 정도로는 재생성/재과금되지 않고, 실적이 실제로 바뀌면 새로 생성됩니다.

## 데이터베이스 (SQLite, `db.py`)
DB 파일: `SetUp/data/app.db` — 별도 설치 필요 없음 (파이썬 기본 내장)

| 테이블 | 하는 일 |
|---|---|
| `stocks` | DART 전체 회사 목록 (약 11만 건, 상장 약 4천 건). **등록 가능 종목 제한이 사라짐** |
| `portfolio` | 등록한 종목·**보유 수량**·메모. 앱을 껐다 켜도 유지됨 |
| `financial_cache` | DART 재무 조회 결과 (7일). DART 무료 키 하루 20,000건 제한 절약 |
| `price_cache` | KRX 일별 종가 (30분). 거래일별로 쌓여 나중에 차트로도 사용 가능 |
| `explanation_cache` | AI 해설 (30일). 같은 지표에 매번 과금되지 않도록 |

**최초 1회 준비:**
```
python db.py sync      # DART 회사 목록을 stocks 테이블에 저장 (30초 정도)
```
앱 사이드바의 "종목 마스터 동기화" 버튼으로도 같은 작업을 할 수 있습니다.

**점검 명령어:**
```
python db.py stats     # 저장 건수 / DB 크기
python db.py list      # 등록된 포트폴리오
python db.py init      # 테이블만 생성
```

캐시 효과: 같은 종목 재조회 시 약 0.59초 → 0.007초 (API 호출 없음)

## 주가 수집(pykrx) 참고
- `python price_client.py 005930` 로 단독 점검 가능 (종목코드 6자리)
- KRX는 로그인 없이 쓸 수 있습니다. "KRX 로그인 실패" 경고는 무시해도 됩니다.
- KRX가 PER/PBR을 직접 주는 `get_market_fundamental`은 응답이 불안정할 때가 많아,
  현재는 **종가만 받아서 DART의 EPS/BPS로 PER/PBR을 직접 계산**합니다.
- 장중 실시간 시세가 필요하면 증권사 API(한국투자 KIS, 키움 등)를 추가로 붙여야 합니다.

## DART API 키 설정
1. https://opendart.fss.or.kr 에서 무료 API 키를 발급받습니다.
2. `DART_API_KEY.env` 파일에 아래 형식으로 저장합니다 (아래 위치 중 아무 곳):
   - `SetUp/DART_API_KEY.env`, `work/DART_API_KEY.env`, `work/Security/DART_API_KEY.env`
   ```
   DART_API_KEY = 발급받은키
   ```
   또는 환경변수 `DART_API_KEY` 로 설정해도 됩니다.
3. 점검: `python dart_client.py 삼성전자 71000` (두 번째 인자는 현재 주가, 생략 가능)
4. 회사명→고유번호 목록은 `SetUp/.cache/corp_code.json` 에 7일간 캐시됩니다.
